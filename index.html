Download besar yang tidak mulai dari nol lagi. Big downloads that never start over.

Tarik membagi satu file ke beberapa koneksi sekaligus dan menyimpan setiap byte yang sudah sampai. Kalau koneksi putus, laptop mati, atau tautannya kedaluwarsa, Anda melanjutkan dari posisi terakhir. Tarik splits one file across several connections and keeps every byte that has arrived. When the connection drops, the laptop dies or the link expires, you carry on from where it stopped.

Satu file, delapan koneksi: hijau sudah tersimpan, indigo sedang berjalan.One file, eight connections: green is saved, indigo is in progress.

Apa yang terjadi pada file AndaWhat happens to your file

Panel rincian di Tarik menampilkan bilah ini untuk setiap download. Begini cara membacanya.Tarik's details panel shows this bar for every download. Here is how to read it.

  1. File dibagi, semua bagian diunduh bersamaanThe file is split and every part downloads at once

    Anda pilih 1 sampai 32 koneksi. Setiap koneksi mengambil potongan file sendiri, jadi kecepatan dari server yang membatasi per koneksi ikut bertambah.You choose 1 to 32 connections. Each one fetches its own slice, so servers that cap speed per connection give you more in total.

  2. Koneksi yang selesai duluan membantu yang lainConnections that finish early help the others

    Begitu satu bagian selesai, koneksinya membelah sisa bagian terbesar milik koneksi lain. Tidak ada koneksi yang menganggur sampai akhir.When a part is done, its connection splits the largest part still running elsewhere. No connection sits idle before the end.

  3. Putus di tengah jalan, tidak ada yang hilangInterrupted halfway, nothing is lost

    Progres hanya dihitung dari byte yang sudah tertulis ke disk. Tutup Tarik, matikan laptop, atau biarkan crash: besok tinggal klik Lanjutkan. Tautan yang kedaluwarsa bisa diganti tanpa membuang yang sudah terunduh.Progress only counts bytes already written to disk. Close Tarik, shut the laptop or let it crash, then press Resume tomorrow. An expired link can be swapped without throwing away what you have.

  4. Tarik memastikan hasilnya file yang samaTarik makes sure it is the same file

    Saat melanjutkan, Tarik mengecek apakah file di server berubah. Kalau berubah, download diulang supaya tidak tersambung jadi file rusak. Tempel SHA-256 atau SHA-512 dari halaman download, dan Tarik mencocokkannya begitu selesai.On resume, Tarik checks whether the file on the server changed. If it did, the download starts over rather than stitching a corrupt file. Paste a SHA-256 or SHA-512 from the download page and Tarik checks it when done.

Yang bisa Anda aturWhat you control

Waktu dan bandwidthTime and bandwidth

  • Antrean dengan jumlah download bersamaan yang Anda tentukan.A queue with as many simultaneous downloads as you choose.
  • Batas kecepatan untuk semua download, atau per download saat sedang berjalan.A speed cap for everything, or per download while it runs.
  • Penjadwal harian, misalnya mulai jam 2 pagi dan berhenti jam 6.A daily schedule, for example start at 2 am and stop at 6.
  • Setelah antrean selesai: keluar, tidurkan, atau matikan komputer, dengan hitung mundur 60 detik yang bisa dibatalkan.When the queue is done: quit, sleep or shut down, after a 60-second countdown you can cancel.

Menangkap tautanCatching links

  • Download dari Chrome, Edge, dan Firefox pindah ke Tarik lengkap dengan cookie login. Kalau Tarik tidak berjalan, browser mengunduh seperti biasa.Downloads from Chrome, Edge and Firefox move to Tarik with their sign-in cookies. When Tarik isn't running, the browser downloads as usual.
  • Salin tautan file .zip, .exe, .mp4, dan sejenisnya, Tarik langsung menawarkan untuk mengunduhnya.Copy a link to a .zip, .exe, .mp4 or similar file and Tarik offers to download it.
  • Impor dan ekspor daftar URL, satu per baris.Import and export URL lists, one per line.

Chrome danand Edge

Unduh ZIP (11 KB)Download ZIP (11 KB)
  1. Ekstrak ZIP (klik kanan, Extract All) ke folder yang akan Anda simpan, misalnya Dokumen\Tarik-ekstensi. Browser memuat ekstensi dari folder itu, jadi jangan dihapus.Extract the ZIP (right-click, Extract All) to a folder you'll keep, for example Documents\Tarik-extension. The browser loads the extension from there, so don't delete it.
  2. Ketik chrome://extensions di bilah alamat Chrome, atau edge://extensions di Edge.Type chrome://extensions in Chrome's address bar, or edge://extensions in Edge.
  3. Nyalakan Developer mode: di kanan atas (Chrome) atau panel kiri (Edge).Turn on Developer mode: top right in Chrome, left panel in Edge.
  4. Klik Load unpacked dan pilih folder hasil ekstrak, yang berisi manifest.json.Click Load unpacked and pick the extracted folder, the one with manifest.json.
  5. Sematkan Tarik lewat ikon puzzle di toolbar. Popup-nya harus menampilkan "Terhubung ke Tarik".Pin Tarik from the puzzle icon in the toolbar. Its popup should say "Connected to Tarik".

Memperbarui: ekstrak ZIP baru ke folder yang sama, lalu klik ikon muat ulang di kartu Tarik pada halaman ekstensi.Updating: extract the new ZIP into the same folder, then click the reload icon on Tarik's card on the extensions page.

Tarik tidak mengirim data tentang Anda.Tarik sends no data about you.

Tidak ada analitik, iklan, atau akun. Ekstensi hanya bicara dengan Tarik di 127.0.0.1, dan cookie serta alamat proxy disimpan terenkripsi dengan Windows DPAPI. Satu-satunya permintaan ke internet di luar download Anda adalah pengecekan versi baru sekali sehari, yang bisa dimatikan.No analytics, ads or accounts. The extension only talks to Tarik at 127.0.0.1, and cookies and the proxy address are stored encrypted with Windows DPAPI. The only request beyond your own downloads is a once-a-day check for a new version, which you can turn off.
