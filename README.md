# Tarik — website dan unduhan

**Tarik** adalah download manager freeware untuk Windows: banyak koneksi per file, bisa dijeda
dan dilanjutkan, integrasi Chrome/Edge/Firefox, dan memperbarui dirinya sendiri.

- Website: https://romyrudiansah.github.io/tarik/
- Unduh installer: https://romyrudiansah.github.io/tarik/#unduh
- Pasang ekstensi browser dari ZIP: https://romyrudiansah.github.io/tarik/#pasang-ekstensi
- **Diskusi, tanya jawab, ide, laporan masalah:** tab [Discussions](https://github.com/romyrudiansah/tarik/discussions)
- Kebijakan privasi: https://romyrudiansah.github.io/tarik/privacy.html

Repo ini hanya berisi hasil build website (HTML, gambar, installer). Tarik adalah freeware dan
kode sumbernya tidak publik; lihat [LICENSE.txt](LICENSE.txt) dan
[THIRD-PARTY-NOTICES.txt](THIRD-PARTY-NOTICES.txt). Isi repo ini ditimpa setiap rilis.
